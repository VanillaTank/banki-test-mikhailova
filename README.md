# Тестовое задание для banki.shop

### Требования
- **Node.js** версии `16.20.2` (или `16.x`)
- **npm** (поставляется вместе с Node.js)

### Установка
1. ****Проверьте версию Node.js****
``` bash
node -v  # должно быть v16.20.2 или 16.x
```
2. **Клонируйте репозиторий**
``` bash  
   git clone <url-репозитория>   
   cd banki-test-mikhailova
```   
3. **Установите зависимости**
``` bash
npm install
```

### Сборка для production
``` bash
npm run build
```
Готовые файлы появятся в папке `dist/`. Их можно размещать на любом статическом сервере (Nginx, Apache, Netlify и т.д.).

### Запуск в режиме разработки
``` bash
npm run serve
```
После запуска приложение будет доступно по адресу`http://localhost:8080`(порт может быть изменён, если занят).  
В этом режиме работает горячая перезагрузка (HMR), все изменения отображаются мгновенно.
